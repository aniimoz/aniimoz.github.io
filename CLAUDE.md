Guidance for Claude Code (and other AI assistants) when working in this repository.

## What this repo is

This is **`aniimoz.github.io`** — a **GitHub Pages user site**. Because the repo
name matches `<username>.github.io`, GitHub Pages serves it automatically at:

> https://aniimoz.github.io

It is a static website repo. There is no backend, no server, and no secrets.

## Deployment model (important)

- Pages source is **GitHub Actions**: `.github/workflows/deploy.yml` publishes
  on every push to `main` (and after the Crawl workflow). **Every push to `main`
  goes live** in ~1 minute. Treat `main` as production.
- **Cache-busting:** Pages caches files 10 min and headers can't be changed, so
  `index.html` loads assets as `…?v=__V__`; Deploy replaces `__V__` with the
  commit SHA. New assets referenced from `index.html` must use `?v=__V__`;
  assets loaded from JS go through `withV()` in `app.js`. See `github-pages` skill.
- Deploy excludes `.git`, `.github`, `.claude`, `CLAUDE.md` from the published site.
- `index.html` at the repo root is the site's entry point.
- The site is static files only (HTML / CSS / JS / images). Use **relative paths**
  for all assets so links work both locally and on the live domain.

### Optional config files (add only when needed)
- `CNAME` — a single line with a custom domain, if one is ever configured.
- `.nojekyll` — add an empty file by this name to **disable Jekyll processing**
  (needed if any file/folder starts with `_` and you are not using Jekyll).

## Current state

The homepage (`index.html`) is the **Aniimo type-chart app**: pick 1–2 elements
to see what they counter / are countered by, a ranked list of the best
secondary types for the chosen primary, plus suggested aniimo for those
types (filterable by role and stage). The secondary-type ranking
(`rankSecondaries` in app.js: score = resist steps − weakness steps, ties →
fewer ×2.56, fewer weaknesses, more distinct resists) reproduces section 7 of
the source doc exactly (order 9/9, ratings 72/72) — re-check if you change it.
"Không hệ phụ" (the single type, `pairProfile(p, null)`) is ranked in the same
list with the same comparator; secondaries below it are labelled ▼ worse
(`compareToMono`), full ties are "= ngang" and placed after it.
Pair cards and the dual-type hero warn "⛔ khắc chế hoàn toàn" (`hardCounters`)
when some type hits the pair ×2.56 AND resists both of its types (×0.625) —
5 of 36 pairs (e.g. Lửa/Thổ by Nước). Warning only; it does not change ranking. All client-side, no build. (There is
no matrix view any more — the user removed it; `MATRIX` in data.js is still
the data behind every calculation.)

```
index.html              ← the app (homepage)
assets/css/styles.css   ← styles
assets/js/data.js       ← ELEMENTS + 9×9 MATRIX + mult() (source of truth)
assets/js/app.js        ← UI logic (vanilla, IIFE)
assets/icons/*.png      ← 9 round element icons (128px, transparent), cut from game art
```

Data is derived from `D:\Projects\aniimo\Aniimo-He-Tuong-Khac.md` (the game's
"Tra Cứu Tương Khắc" screen). If `MATRIX` changes, re-verify against that file's
section 4 before pushing.

## Aniimo data (crawled)

`assets/data/aniimo.json` — all aniimo (name, elements as data.js ids, roles,
region, form, stats, image URL, wiki URL), generated by
`.github/scripts/crawl-aniimo.mjs` from https://wiki.aniimo.com/vi (the Nuxt
pages embed JSON in `<script id="__NUXT_DATA__">`; no browser needed).

- **Every form is its own entry** (Basic, Prismana, Highland, Snowfield,
  Nighttime…): forms often carry different types than the base form. The list
  page only has default forms; the crawler follows each detail page's
  `morphologyList` to find the rest (130 list entries → ~259 forms / 120
  aniimo). Numbers are **per region** (#001 in one region ≠ #001 in another),
  so the unique key is region + number + form; `family` (lower-cased name)
  groups forms of the same aniimo; `baseForm` marks the Basic Form.
- Refresh it via GitHub **Actions → Crawl → Run workflow** (manual only). The
  workflow commits as `github-actions[bot]` only when data changed, then asks
  Pages to rebuild. Run locally: `node .github/scripts/crawl-aniimo.mjs`
  (`CRAWL_DETAILS=false` for list-only).
- The script refuses to overwrite the file if output looks broken (<50 entries,
  big drop vs. previous, >20% detail pages failing). Don't hand-edit the JSON.
- Content/images belong to the game publisher: credit the wiki, hotlink images
  from their CDN rather than copying them into the repo, keep crawling polite.

## Conventions

- Keep the site **static and dependency-light**; prefer plain HTML/CSS/JS unless
  the user explicitly asks for a framework or static-site generator.
- Test changes in a browser (locally via `python -m http.server`, or the live
  site) before/after pushing, since a push to `main` publishes immediately.
- Asset filenames: lowercase ASCII slugs, no spaces or Vietnamese diacritics.
